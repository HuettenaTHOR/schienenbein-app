# Schienbein Trainingsplan

Übungsplan gegen Schienbeinschmerzen innen bei nach innen knickenden Sprunggelenken. Die Seite läuft als statische Webseite auf GitHub Pages.

Live: https://huettenathor.github.io/schienenbein-app/

## Inhalt

| Datei | Zweck |
|---|---|
| `index.html` | Die Webseite mit allen Übungen, Steigerung und Wochenprotokoll |
| `.nojekyll` | Sorgt dafür, dass GitHub die Dateien unverändert ausliefert |
| `README.md` | Diese Anleitung |

## GitHub Pages einschalten

1. Im Repo auf **Settings** gehen.
2. Links **Pages** wählen.
3. Bei **Source** die Option **Deploy from a branch** wählen.
4. Bei **Branch** `main` und `/ (root)` einstellen und **Save** klicken.
5. Nach ein bis zwei Minuten ist die Seite unter dem Live Link oben erreichbar.

## PDF

Der Knopf **Als PDF speichern** öffnet den Druckdialog. Dort als Ziel „Als PDF speichern“ wählen. Die Seite hat eine eigene Druckansicht mit weißem Hintergrund.

Optional kannst du zusätzlich eine fertige PDF anbieten. Lade sie unter dem Namen `Schienbein_Trainingsplan.pdf` ins Hauptverzeichnis hoch. Dann erscheint auf der Seite automatisch der Knopf **PDF herunterladen**.

## Hinweise

* Das Wochenprotokoll speichert Häkchen und Schmerzwerte nur im Browser des jeweiligen Geräts. Am Handy und am Laptop stehen also getrennte Einträge.
* Der Plan ersetzt keine ärztliche oder physiotherapeutische Untersuchung.
